Overview

Machine learning algorithms allow computers to learn complex patterns from empirical data, including text, images, videos, sound, sensor measurements, and structured databases. This course provides a broad introduction to machine learning, emphasizing fundamental principles, mathematical derivation, algorithm design, and implementation.

Core topics include statistical learning, parameter estimation, Bayesian learning, clustering, dimensionality reduction, discriminative classifiers, regression, and kernel methods. Selected connections to modern machine learning illustrate how these foundations relate to current methods and applications.

  • Statistical and Bayesian learning
  • Clustering and latent-variable models
  • Dimensionality reduction
  • Linear and kernel classifiers
  • Regression and model evaluation
  • Connections to modern machine learning

Learning Outcomes

  1. Explain and mathematically derive common machine learning algorithms from first principles.
  2. Implement machine learning algorithms and apply them to real-world problems.
  3. Evaluate competing methods using theoretical reasoning and empirical evidence.
  4. Design machine learning solutions that address the limitations of existing approaches.

Assignments

Assignments combine theoretical analysis and programming, including derivations, implementation of selected algorithms, experiments on data, and interpretation of model behavior.

Course Project

The project addresses a real-world machine learning problem through problem formulation, data preparation, model selection, implementation, baselines, experimental evaluation, interpretation, and a final presentation and report.
